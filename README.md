# Samir Sen Portfolio

A dependency-free, responsive portfolio site for Samir Sen. It uses semantic HTML, CSS custom properties, and a small JavaScript layer for the theme toggle, project detail expansion, and reveal animations.

## Run locally

No build step or package installation is required. From this directory, run any static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Upload the repository to any static host such as GitHub Pages, Netlify, Vercel, or AWS S3. The entry point is `index.html`; there are no environment variables or server-side dependencies.# Samir-Sen
