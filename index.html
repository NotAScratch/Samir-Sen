01 · Final-year project, 2025

Real-time object detection with distance and direction

A pipeline that detects objects in live video and estimates how far away each one is and in which direction, so a robot can act on what it sees.

The model runs behind a FastAPI inference service, with a Spring Boot web app and user login in front, all deployed with Docker.

02 · Edge AI

Orientation and spatial edge intelligence

LiDAR and depth sensing combined with on-device PyTorch inference on a Jetson Nano, so the robot reasons about its surroundings without remote computing.

Keeping inference next to the sensor shortens the loop between sensing and reacting.

Device
Jetson Nano
Sensors
LiDAR, depth
Inference
PyTorch, on device
